# Roadmap

This roadmap outlines planned capabilities and milestones for future NetForge releases.

## Current Release (v4.0.0)

- Standardized Farama interfaces: PettingZoo parallel/AEC and Gymnasium.
- SIEM telemetry pipeline with Sysmon-formatted event buffering and TF-IDF/dense vectorization.
- Durative action queuing and conflict resolution mechanics.
- NetForge Arena with `train`, `dev`, and `hidden` evaluation splits.
- Benchmark suite including Elo self-play tournaments, throughput profilers, and capability cards.
- Scenario catalog covering healthcare ransomware, enterprise APT, cloud IAM, and OT physical control systems.

## Future Development

- **Farama Gymnasium / PettingZoo Listing**: Formal integration into official ecosystem documentation.
- **Extended Pretrained Baselines**: Checkpoint zoo covering MAPPO, QMIX, and GNN policies across all scenarios.
- **Hosted Competition Leaderboard**: Automated evaluation harness for submission verification.
- **Expanded Hardware-in-the-Loop Emulation**: Deeper integration with containerized Vulhub ranges.
